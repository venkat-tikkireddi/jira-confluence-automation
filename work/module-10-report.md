````markdown
# Weekly Status Report Instructions

- Generate the report in Markdown.
- Use these sections in this order: `Accomplishments`, `Blockers`, `Next Week`.
- Use bullet points for all section content; do not use paragraphs, tables, or numbered lists.
- Keep the entire report to a maximum of 20 lines, counting headings and blank lines.
- Use a professional, concise tone.
- Use factual, specific updates; include outcomes, owners, or dates when known.
- Avoid fluff, filler, vague praise, and unsupported claims.
- If a section has no updates, include a single bullet stating `None`.
````
